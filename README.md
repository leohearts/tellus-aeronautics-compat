# Tellus Aeronautics Compat

Makes Sable's air pressure curve usable in [Tellus](https://modrinth.com/mod/tellus) worlds,
so airships and other Sable contraptions keep flying at Tellus altitudes.

## The problem

Sable's default curve is `exp(-0.004 * (y - sea level))`. That `0.004` is tuned for vanilla
384 block tall worlds, where pressure halves every 173 blocks. Tellus worlds are orders of
magnitude taller — a mountain range can start above y=1000 — so an airship loses all lift
long before it gets anywhere useful.

## What this mod does

On server start it walks every dimension, picks out the ones generated by Tellus, reads the
world's own `EarthGeneratorSettings` (`height_offset`, `terrestrial_height_scale`,
`oceanic_height_scale`, experimental height increase) and rebuilds the pressure curve from
them using a real atmospheric scale height of 8500 m. The result is registered with Sable at
a higher priority than any datapack-provided curve, so it wins.

Dimensions Tellus does not generate (the Nether, the End, modded dimensions) are left alone.

Because the curve is derived from the world's settings rather than hardcoded, it follows
whatever the world was created with, including the experimental height increase option.

## Requirements

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1+ |
| [Sable](https://modrinth.com/mod/sable) | 2.0+ |
| [Tellus](https://modrinth.com/mod/tellus) | 0.8+ |

Install on the server. It is a server-side mod — Sable sends the resulting physics to
clients — but installing it on both sides is harmless.

## Configuration

None. The curve comes from the world's Tellus settings.

## Building

```sh
./gradlew build
```

The two compile-time dependency jars are downloaded from the Modrinth CDN into `libs/` on
the first build and are not committed to the repository. The output jar lands in
`build/libs/`.
